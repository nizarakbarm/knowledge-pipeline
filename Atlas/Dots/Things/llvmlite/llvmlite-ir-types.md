# llvmlite IR Types

The `llvmlite.ir.Type` hierarchy defines all types used in LLVM IR construction. All values are explicitly typed, and types are immutable once instantiated.

## Summary



## Key Concepts

### Base Type Class
`Type` is the abstract base for all types. Key methods:
- `as_pointer(addrspace=0)` — Create pointer type pointing to this type
  
  > [!Note]
  > **Address space 0** is the default memory space. GPU programming uses address spaces 1 (global), 3 (local), and 4 (constant).
  
- `get_abi_size(target_data)` — Get size in bytes for this type on the target platform
- `get_abi_alignment(target_data)` — Get memory alignment boundary in bytes
- `get_element_offset(target_data, position)` — Byte offset for struct element at given index

> [!Note]
> **ABI queries call into LLVM C++ API.** `get_abi_size()`, `get_abi_alignment()`, and `get_element_offset()` require a `TargetData` instance from the binding layer and execute native LLVM code.

- `__call__(value)` — Convenience to create a Constant of this type

### Atomic Types
- `IntType(bits)` — Integer type with specified bit width
  - `width` — Bit width attribute
- `HalfType` — 16-bit float (GPU memory optimization)
- `FloatType` — 32-bit IEEE 754 float
- `DoubleType` — 64-bit IEEE 754 float
- `VoidType` — No return value (function return type only)

### Pointer Types
**Typed Pointers** (deprecated): `PointerType(pointee, addrspace=0)`

> [!Note]
> **Typed pointers** explicitly know what they point to. They are being phased out in favor of opaque pointers for LLVM 20+.

- `pointee` — Type being pointed to (e.g., IntType(32))
- `addrspace` — Memory space identifier (platform-specific)

**Opaque Pointers**: `PointerType(addrspace=0)`

> [!Note]
> **Opaque pointers** do not carry type information — the pointee type is determined by usage context. This is the modern LLVM standard.

- No pointee type specified
- Environment override: `LLVMLITE_ENABLE_IR_LAYER_TYPED_POINTERS=0`
- Python override: `llvmlite.ir_layer_typed_pointers_enabled = False`

### Aggregate Types

> [!Note]
> **Aggregate Base:** `Aggregate` is the base class for array, vector, and struct types. It provides the `elements` attribute — a tuple-like immutable sequence of element types.

- `ArrayType(element, count)` — Fixed-size homogeneous array
- `VectorType(element, count)` — SIMD vector for parallel operations
- `LiteralStructType(elements, packed=False)` — Anonymous inline struct
  
  > [!Note]
  > **Packed structs** eliminate padding between fields, matching C `#pragma pack(1)` behavior.
  
  - `packed=False` — If `True`, disables padding between fields
> [!Warning]
> **Don't instantiate directly.** Use `Context.get_identified_type(name)` to create named structs. Created without body (opaque). Define body with `set_body(*elems)`.

- `IdentifiedStructType` — Named struct referenced by name (supports forward declarations and recursive types)

### Function Types
`FunctionType(return_type, args, var_arg=False)` — Function signature type

> [!Note]
> **Varargs** (`var_arg=True`) enables C-style variadic functions like `printf()` that accept additional untyped arguments.

- `return_type` — Type of the return value (or VoidType)
- `args` — Tuple of argument types
- `var_arg` — Whether function accepts variable arguments

### Special Types
- `LabelType` — Control flow target for basic blocks (auto-generated by IRBuilder)

> [!Note]
> **Metadata types** store debug information and optimization hints that do not affect program execution.

- `MetaDataType` — Debug info / optimization metadata (do not instantiate)

## Code Example

```python
from llvmlite import ir

# Integer and float types
int32 = ir.IntType(32)
double = ir.DoubleType()

# Pointer type (default address space 0)
int32_ptr = int32.as_pointer()

# GPU address space example (OpenCL global memory)
global_ptr = int32.as_pointer(addrspace=1)

# Function type: int32 (double, int32*)
fnty = ir.FunctionType(int32, (double, int32_ptr))

# Variadic function type (like printf)
vararg_fnty = ir.FunctionType(int32, (int32_ptr,), var_arg=True)

# Struct type (with padding)
structty = ir.LiteralStructType([int32, double])

# Packed struct (no padding, C #pragma pack(1))
packed_struct = ir.LiteralStructType([int32, double], packed=True)

# Array type
arrty = ir.ArrayType(int32, 10)

# SIMD vector type (4 x int32)
vec = ir.VectorType(int32, 4)
```
